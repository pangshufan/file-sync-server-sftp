## 已知边界

- 自动确认只能证明 server 判断完整传出；目录项和删除仍需主动确认。
- 仅提供最新文件内容，无历史快照或块级差分。
- 同 userid 多个客户端共享状态，关闭单连接限制也不会产生独立设备进度。
- 文件系统路径隔离不针对本机恶意进程并发替换目录。
- 公开发布前需从临时 `simple-sync.invalid` 命名空间迁移到自有域名。
- Windows/Linux 及百万真实文件的扫描/传输尚未验收。
